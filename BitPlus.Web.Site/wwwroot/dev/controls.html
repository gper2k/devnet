태그 목록

1. 쓰기 모드 ul.tags > li > input

자식 li 에 입력항을 두면 쓰기 모드로 동작합니다. 입력 후 Enter(또는 change) 시 입력항 li 앞에 태그가 추가되고 입력은 비워집니다. 빈 값과 중복(대소문자 무시)은 추가하지 않으며, 태그의 삭제 버튼으로 제거합니다. 이벤트는 site.ts body 위임으로 처리되어 별도 스크립트가 필요 없습니다.

  • ASP.NET
  • TypeScript
tag 이벤트: - 
<ul class="tags">
    <li><span>ASP.NET</span><button type="button"><i class="fi fiDismiss"></i></button></li>
    <li><input type="text" placeholder="태그 입력 후 Enter" /></li>
</ul>

// 추가/삭제 감지 (선택)
list.addEventListener("tag", e => console.log(e.detail.text, e.detail.add));

2. 읽기 전용 ul.tags

입력항이 있는 li 가 없으면 표시 전용 태그 목록입니다. 삭제 버튼 없이 텍스트만 둡니다.

  • 공지
  • 이벤트
  • 업데이트
<ul class="tags">
    <li>공지</li>
    <li>이벤트</li>
</ul>

3. 값 바인딩 / 수집 JS

common.setTags(list, tags) 로 태그를 채우고(쓰기 모드면 삭제 버튼 포함), common.getTags(list) 로 태그 텍스트 배열을 얻습니다.

common.setTags(list, ["C#", "Razor", "SCSS"]);
const tags = common.getTags(list); // ["C#", "Razor", "SCSS"]

날짜·시간 입력

1. 날짜 .datePick

태그만 선언하면 site.ts 가 초기화합니다(나중에 추가되는 모달 안의 태그도 자동). 누르면 달력 팝업이 열리고(위쪽 년도를 누르면 10년 단위 년도 선택, 월을 누르면 12개월 선택 화면 — 문화권과 상관없이 4자리 년도 - 2자리 월 숫자로 표시), 아래의 오늘·초기화 버튼을 지원합니다. 값은 yyyy-MM-dd, data-min/data-max 밖의 날짜는 선택할 수 없습니다.

change 이벤트: - 
<div class="datePick" data-name="day" data-value="2026-10-14"
     data-min="2026-10-01" data-max="2026-12-31" data-placeholder="날짜 선택"></div>

const el = document.querySelector(".datePick");
el.value;                 // "2026-10-14" (비어 있으면 "")
el.value = "2026-11-02";  // 쓰기 (이벤트 없음)
el.addEventListener("change", () => console.log(el.value));

2. 시간 .timePick

누르면 시·분 스피너 팝업이 열립니다. 위/아래 화살표(또는 키보드 ↑↓)로 올리고 내리면 팝업 안에서만 바뀌고, 적용 버튼(또는 입력칸에서 Enter)을 눌러야 값이 정해집니다(적용하지 않고 닫으면 버려짐). 초기화 버튼은 값을 비웁니다. 숫자를 직접 입력할 수도 있습니다. data-step 으로 분 단위 간격(기본 1)을 정합니다. 값은 HH:mm.

change 이벤트: - 
<div class="timePick" data-name="time" data-value="15:03" data-step="5"></div>

3. 날짜 + 시간 .dateTimePick

날짜와 시간을 따로 입력받는 한 쌍입니다. 값은 yyyy-MM-ddTHH:mm(사용자의 로컬 시간)이고, 날짜만 고르면 시간은 현재 시(분 00), 날짜를 지우면 시간도 비워집니다. 시간 팝업도 값이 없으면 현재 시(분 00)에서 시작합니다.

value: - 
<div class="dateTimePick" data-name="start" data-value="2026-10-14T09:30"></div>

const el = document.querySelector(".dateTimePick");
el.value = "2026-12-24T18:00";
const utc = el.value ? new Date(el.value).toISOString() : null; // 서버로 보낼 때 UTC 로

4. 기간 설정 모달 common.periodEdit

시작~종료 값을 정하는 공용 모달입니다(위 날짜·시간 컨트롤 사용). 발행 기간뿐 아니라 어떤 기간·범위 입력에도 쓸 수 있도록 제목·아이콘·라벨·안내 문구와 입력 형식(날짜+시간 / 날짜만 / 시간만)을 호출할 때 바꿀 수 있습니다.

  1. await common.periodEdit(시작, 끝, 옵션) 으로 엽니다. 시작·끝은 비워 두면(null) 그쪽은 제한 없음입니다.
  2. 3번째 인자는 제목 문자열 또는 옵션 객체이며 모두 생략할 수 있습니다(생략하면 "발행 기간" 문구).
  3. 사용자가 적용을 누르면 { start, end }, 취소(Esc 포함)면 null 을 돌려줍니다. 초기화는 두 값을 모두 비웁니다.
  4. 끝이 시작보다 앞서면 적용되지 않고 알림이 나옵니다. 모달 너비는 입력 형식에 맞게 자동 조정됩니다.
결과: - 
const result = await common.periodEdit(start, end); // start/end: ISO 8601 UTC 또는 null
if (result) { /* { start, end } */ }              // 취소하면 null

// 발행 기간이 아닌 용도: 3번째 인자에 제목 문자열 또는 문구 옵션 (모두 생략 가능, info: "" 이면 하단 안내 숨김)
await common.periodEdit(start, end, { title: "예약 기간", icon: "fiCal", startLabel: "시작", endLabel: "종료", info: "" });

// 입력 형식: 날짜+시간(기본) / 날짜만 / 시간만
await common.periodEdit(start, end, { mode: "datetime" });

// 날짜만 / 시간만 받기 (date: "yyyy-MM-dd", time: "HH:mm" 그대로 주고받음, 모달 너비도 자동 조정)
await common.periodEdit("2026-10-14", null, { mode: "date", title: "휴가 기간" });
await common.periodEdit("09:00", "18:00", { mode: "time", title: "근무 시간" });
이름유형설명
.datePick / .timePick / .dateTimePickCSS태그 선언만으로 쓰는 날짜 / 시간 / 날짜+시간 컨트롤
data-valueHTML초기값 (날짜 yyyy-MM-dd, 시간 HH:mm, 날짜시간 yyyy-MM-ddTHH:mm)
data-nameHTML있으면 같은 이름의 hidden input 이 값을 따라가 폼 전송에 쓸 수 있음
data-min / data-maxHTML선택 가능한 날짜 범위 (날짜, dateTimePick 은 날짜 부분)
data-stepHTML시간의 분 단위 간격 (1~30, 기본 1)
data-placeholderHTML값이 없을 때 표시할 글자
el.valueproperty값 읽기/쓰기 (로컬 시간, 비면 빈 문자열)
change (event)Event사용자가 값을 바꾸면 요소에서 발생 (bubbles, 쓰기로 바꾼 값은 발생하지 않음)
common.periodEdit(start, end, title?)method기간 설정 모달 열기(title: 제목 문자열 또는 { title, icon, startLabel, endLabel, info } 로 문구 교체), 확인 시 { start, end } (UTC ISO 또는 null), 취소 시 null
