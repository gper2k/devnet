수직 + 세그먼트 툴바 .toolBar.vertical .toolBar.segmented

.vertical은 세로 배치, .segmented는 항목 간 구분선 자동. 두 변형을 나란히 보여줌.

클래스/속성 타입 설명
.toolBarCSS기본 수평 툴바 래퍼
.toolBar.floatingCSSPill 형태 플로팅 툴바
.toolBar.segmentedCSS세그먼트 스타일 (항목 간 구분선 자동)
.toolBar.verticalCSS세로 배치 툴바
.toolBar.flatCSS배경/테두리 없는 flat 스타일
.itemCSS기본 툴바 버튼
.item.iconOnlyCSS아이콘만 표시 (정사각형)
.item.stackedCSS아이콘+텍스트 세로 스택
.actionBtnCSS강조 액션 버튼 (오른쪽 배치용)
.dividerCSS수직 구분선
.spaceCSS남은 공간 채움 (flex: 1)
.dropDown.selectBoxCSS선택값 표시 드롭다운
.dropBox.upCSS드롭박스 위로 열림
.dropBox.rightCSS드롭박스 우측 정렬
data-action="toggle"HTML클릭 시 active 토글
data-group="name"HTML같은 그룹 내 단일 선택
.sm / .lgCSS크기 스케일 변형
.main .point .primary 등CSS9대 테마 색상
