컨트롤 규격 검증

버튼 & 입력항 높이 일치 (2.6em) button input select

버튼과 입력항은 동일한 2.6em 높이와 pill 라운딩. 나란히 배치 시 정렬 보장.

<div style="display:flex;gap:0.6em;align-items:center;flex-wrap:wrap;">
  <input type="text" placeholder="검색어 입력..." />
  <button class="btn">검색</button>
  <button class="btn point">예약 신청</button>
  <button type="button" class="btn">
    <i class="fi fiUpload"></i><span>파일 첨부</span>
    <input type="file" />
  </button>
  <select><option>주간</option><option>월간</option></select>
</div>

9대 테마 색상 버튼 .main .point .primary

9개 색상 테마 클래스. 클릭 시 translateY 없이 scale(0.98) + 인셋 그림자 피드백.

<button class="btn">기본</button>
<button class="btn point">Point</button>
<button class="btn main">Main</button>
<button class="btn sub">Sub</button>
<button class="btn primary">Primary</button>
<button class="btn success">Success</button>
<button class="btn danger">Danger</button>
<button class="btn warning">Warning</button>
<button class="btn info">Info</button>
<button class="btn deco">Deco</button>

버튼 크기 단계 (em 비례 스케일) .xxs .xs .sm .lg .xl .xxl

font-size 기반 em 비례 크기 스케일. 버튼과 입력항 모두 동일 클래스로 확장.

<button class="btn point xxs">XXS</button>
<button class="btn point xs">XS</button>
<button class="btn point sm">SM</button>
<button class="btn point">MD (기본)</button>
<button class="btn point lg">LG</button>
<button class="btn point xl">XL</button>
<button class="btn point xxl">XXL</button>

입력항 상태 input textarea

포커스 시 --lineFocusColor 글로우, readonly/disabled 자동 스타일 처리.

<input type="text" placeholder="일반 입력항" />
<input type="text" readonly value="읽기 전용 (readonly)" />
<input type="text" disabled value="비활성 (disabled)" />
<textarea placeholder="여러 줄 텍스트..."></textarea>

커스텀 컨트롤 (체크박스, 라디오, 토글) label.check label.radio label.toggle

label.check / label.radio / label.toggle — 9대 테마색 + 크기 클래스 지원.

<!-- 체크박스 -->
<label class="check"><input type="checkbox" checked /><span>기본</span></label>
<label class="check point"><input type="checkbox" checked /><span>Point</span></label>
<label class="check" disabled><input type="checkbox" disabled /><span>Disabled</span></label>

<!-- 라디오 -->
<label class="radio"><input type="radio" name="r" checked /><span>옵션 A</span></label>
<label class="radio point"><input type="radio" name="r" /><span>옵션 B</span></label>

<!-- 토글 -->
<label class="toggle"><input type="checkbox" checked /><span><i></i></span><span>ON</span></label>
<label class="toggle point"><input type="checkbox" /><span><i></i></span><span>Point</span></label>
<label class="toggle" disabled><input type="checkbox" disabled /><span><i></i></span><span>Disabled</span></label>

입력 그룹 .inputGroup

접두사/접미사 텍스트 애드온, 버튼 결합, 드롭다운 결합. 포커스 시 그룹 전체에 단일 포커스링.

@
전체
  • 전체 검색
  • 이름
  • 부서
<!-- 접두사 + 입력 -->
<div class="inputGroup">
  <span>@</span>
  <input type="text" placeholder="아이디" />
</div>

<!-- 입력 + 검색 버튼 -->
<div class="inputGroup">
  <input type="text" placeholder="검색어 입력..." />
  <button type="button" class="btn primary"><i class="fi fiSearch"></i><span>검색</span></button>
</div>

<!-- 드롭다운 + 입력 + 버튼 -->
<div class="inputGroup">
  <div class="dropDown">
    <header>전체</header>
    <ul><li>전체 검색</li><li>이름</li><li>부서</li></ul>
  </div>
  <input type="text" placeholder="검색어" />
  <button type="button" class="btn point"><i class="fi fiSearch"></i></button>
</div>
클래스/속성 타입 설명

type="button" class="btn" + input[type=file]HTML파일 업로드 버튼 오버레이

label.radioCSS라디오 커스텀 래퍼
label.toggleCSS토글/스위치 커스텀 래퍼
label.{control}.{color}CSS테마 색상 적용
label.{control}[disabled]HTML비활성화
