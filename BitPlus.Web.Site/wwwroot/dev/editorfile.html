에디터

1. 에디터 (2개 인스턴스, 엔진 선택) common.makeEditor

소유자 키가 다른 에디터 두 개입니다. 사이트는 에디터 엔진을 Jodit(기본), SunEditor 두 가지 중 고를 수 있고, 아래 선택 상자로 인스턴스마다 엔진을 바꿔 볼 수 있습니다(바꾸면 현재 본문을 유지한 채 다시 만듭니다). 어느 엔진이든 호출 코드와 업로드·복사 동작은 같습니다. A 는 SunEditor, B 는 Jodit 로 시작하므로 서로 다른 엔진 사이의 이미지 복사도 확인할 수 있습니다. 이미지는 api/system/editor/file 로 업로드되어 /api/system/editor/file/{id}/{년월 hex}{MIME hex} 경로로 들어갑니다(이미지 버튼, 파일 붙여넣기·끌어놓기 모두). 에디터 A 의 이미지를 복사해 B 에 붙여넣으면 서버에서 B 소유로 복사한 뒤 경로를 바꿔 넣습니다. 미디어(동영상/오디오/임베드) 기능은 뺐습니다.

에디터 A — ownerKey
에디터 B — ownerKey 
-
// 에디터 파일(CSS/JS)은 common 이 공급자(new Site 의 editor/editorPath)에 맞게 알아서 로드한다
// 업로드(이미지 버튼, 파일 붙여넣기·끌어놓기)와 다른 소유자 이미지 붙여넣기 복사를 처리하는 공용 에디터
const editor = await common.makeEditor(textarea, {
    ownerType: "Content",
    ownerKey: contentId,
    password: "",                // 비인증 등록 암호 (선택)
    height: "20em",              // 기본 20em
    onFiles: (kind, data) => {}, // "upload" | "copy" 결과 (선택)
    siteCss: false,              // true: 편집 영역에 사이트 CSS 연결 (선택)
    rawHtml: false,              // true: 걸러내기 끄기 (선택)
    options: {},                 // 엔진 고유 옵션 (선택)
});
const html = editor.getHtml();   // setHtml(html), focus(), destroy(), native(엔진 원본)

에디터 엔진 교체 new Site(options)

사이트 전체 에디터는 관리자 "시스템 설정 > 사이트 정보" 의 주 에디터로 정합니다(레이아웃이 new Site({ editor }) 로 넘김, 비었거나 모르는 이름이면 site.ts 생성자의 기본 jodit). 페이지마다 다르게 쓰려면 new Site({ editor: "suneditor" }), 경로만 바꿔도 되며(editorPath: "/lib/jodit" → 폴더 이름으로 공급자 선택), 새 엔진은 IEditorProvider 를 구현해 registerEditor 로 등록하면 됩니다. 에디터 UI 언어는 영어가 기본이고 현재 UI 문화권(ko 등)을 공급자가 지원하면 그 언어로 나옵니다.

const common = new Site();                                     // 기본: jodit
const common = new Site({ editor: "suneditor" });              // 에디터 이름으로 선택 (경로는 공급자 기본 경로)
const common = new Site({ editorPath: "/lib/suneditor" });     // 경로만 줘도 폴더 이름으로 공급자 선택

// 새 엔진 추가: IEditorProvider(name, defaultPath, languages, assets, content, create) 구현 후 등록
common.registerEditor(new MyEditorProvider());
const common = new Site({ editor: "myeditor" });

2. 본문 샌드박스 출력 common.renderContent

미리보기 버튼으로 에디터 본문을 allow-same-origin 없는 샌드박스 iframe 에 출력합니다. 내용 높이에 맞춰 iframe 높이가 자동 조정되고, 본문 스크립트는 부모 페이지에 접근하지 못합니다. "스크립트 테스트" 는 스크립트가 든 HTML 을 출력해 차단 여부를 보여줍니다.

common.renderContent(document.getElementById("contentBody"), html);

3. 이미지 조회 확인 GET api/system/editor/file/{id}/{yyyyMM hex}{MIME hex}

에디터에 들어간 이미지 목록입니다. 항목을 누르면 응답 상태와 헤더(Content-Type, 캐시, nosniff, CSP)를 보여주고, "년월 변조"/"형식 변조(svg)" 는 링크의 년월·MIME 을 바꿔 404 가 오는지 확인합니다.

    -
    이름유형설명
    POST api/system/editor/fileAPI업로드. 쿼리 ownerType(32자), ownerKey(64자), 폼 file(여러 개), password → data [{ url, name, size }]
    POST api/system/editor/file/copyAPI폼 ownerType, ownerKey, ids(반복), password → data 원본 Id → 새 URL
    GET api/system/editor/file/{id}/{info}API공개 조회. {id}/{yyyyMM 16진수 5자리}{"image/" 뺀 MIME 16진수}
    EditorFile.SyncAsyncC#글 저장 시 호출. 본문 참조 파일 등록, 미참조 파일 삭제 (keepRegistered: 이력 사용 규칙의 수정 저장)
    EditorFile.DeleteOwnerAsyncC#글 삭제 시 소유자의 파일 전체 삭제
    new Site({ editor, editorPath })option에디터 엔진 선택. editor: 공급자 이름(jodit(기본), suneditor), editorPath: 엔진 파일 경로(생략 시 공급자 기본 경로)
    common.registerEditor(provider)method새 에디터 공급자(IEditorProvider) 등록
    common.editorName / editorPathproperty현재 에디터 공급자 이름 / 파일 경로 (이 샘플처럼 바꾼 뒤 makeEditor 호출하면 그 엔진으로 생성)
    common.makeEditor(textarea, option)method현재 공급자로 textarea 를 에디터로 바꿈 → IEditor(getHtml, setHtml, focus, destroy, native)
    common.renderContent(target, html)method샌드박스 iframe 출력 + 높이 자동 조정
