# BitPlus.Web.Site/wwwroot/img (사이트 이미지)

사이트 기본 이미지. `banners/` = 배너·디자인 위젯 샘플 이미지(img1~5), `banners/dashboard.jpg` = 관리 대시보드 화면(홈 히어로 노트북 화면 기본값, 1440×900). `person/` = 샘플 인물, `sample/` = 샘플 자료(WebP, 긴 변 최대 1600px, 품질 80 — 설치 시드의 샘플 글·홈/포탈 기본 배치가 참조). `brands/` = 외부 로그인 서비스 로고 SVG(24×24, `OAuthPreset.BrandIcon` — 로그인 버튼·내 정보 외부 로그인 연결 카드).
